A: The privacy of contacts is enforced by Postgres itself, specifically through Row Level Security (RLS) [1]. The ownership rule dictates that every policy on the `contacts` table reduces to the predicate `auth.user_id() = user_id` [5]. This means that the Data API verifies the JWT signature before Postgres processes the query, and the RLS policies ensure that a user can only see or change data where `auth.user_id()` matches the `user_id` [5]. For example, when Account B signs in, the contacts list is empty even if rows exist in the table for Account A [6].
