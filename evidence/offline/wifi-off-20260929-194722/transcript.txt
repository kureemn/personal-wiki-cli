════════ 2. Help (a fresh CLI process for every command) ════════
$ ./wiki --help
usage: wiki [-h] command ...

Personal wiki CLI: a local Gemma harness over your own notes (chat, ask, search, ingest).

positional arguments:
  command
    ingest    read sources in vault/raw, generate linked wiki notes, rebuild
              indexes
    search    show original matching passages (no model answer)
    ask       standalone cited answer from your sources
    chat      personal assistant with conversation context
    eval      run the fixed ask-mode tests and write evidence cards
    check     verify wiki links, headings and unchanged sources
    rename    rename a wiki note and update every link to it
    reindex   rebuild index.md, catalog and retrieval index (no generation)
    status    model, runtime, memory and device information

options:
  -h, --help  show this help message and exit

modes:
  search  retrieval only: original passages + paths, never calls the language model
  ask     standalone factual answer from retrieved raw passages, with citations,
          or "INSUFFICIENT EVIDENCE" (no chat history, no persona)
  chat    personal assistant with conversation memory; looks up notes only when needed

examples:
  wiki ingest vault/raw
  wiki search "row level security"
  wiki ask "What mean score did the trained Pac-Man agent get?"
  wiki chat
  wiki eval                 # run the 4 fixed ask-mode tests -> evidence/ask/
  wiki check                # verify links, headings and unchanged sources

configuration (environment variables):
  WIKI_MODEL        chat/answer model   (default gemma4:e4b-it-q4_K_M)
  WIKI_EMBED_MODEL  embedding model     (default embeddinggemma:300m)
  OLLAMA_HOST       local Ollama server (default http://127.0.0.1:11434)

required inputs: Ollama running locally with both models pulled (`ollama pull ...`);
sources as .md/.txt files in vault/raw/. Instructions: prompts/*.md.
