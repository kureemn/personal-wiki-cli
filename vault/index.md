## Concepts

Ideas and techniques the projects rely on. Descriptions are general definitions written by the model; the project lines inside each note cite my sources.

- [[Attention]]: Attention mechanisms allow a model to weigh the importance of different parts of the input sequence when processing a token.
- [[Client-Side Validation]]: Validation logic implemented in the client-side code to provide immediate user feedback before data submission.
- [[Deep Q-Network]]: A type of reinforcement learning algorithm that uses a neural network to estimate the optimal action-value function (Q-value).
- [[Embedding Vector]]: An embedding vector is a numerical representation of a word or token, capturing its semantic meaning in a multi-dimensional space.
- [[Exploration]]: A strategy where an agent occasionally takes random actions to discover new states and potential rewards.
- [[JWT Authentication]]: JSON Web Tokens are used to securely transmit information between parties, often used for session management.
- [[Language Model]]: A language model is a statistical tool that predicts the probability of a sequence of words occurring in a given text.
- [[Learning Rate]]: A hyperparameter that controls the step size taken when updating the network's weights during training.
- [[Replay Memory]]: A buffer used in reinforcement learning to store past experiences, allowing the agent to sample data randomly for training.
- [[Row Level Security]]: RLS policies restrict which rows in a database table a specific user can see or modify.
- [[Serverless Database]]: A database service that manages infrastructure automatically, often without requiring dedicated server management.
