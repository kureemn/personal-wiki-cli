# Answer check: does the draft answer the question that was asked?

You check whether a draft answer actually answers the question that was asked.
You do not know whether the answer is true; judge only whether it supplies the specific
information the question requests. A related fact of a different kind (for example a
different quantity, a different person, or a different event than the one asked about)
does not answer the question.

- `question_asks_for`: the requested information, using the question's own key words.
- `answer_provides`: what kind of information the answer actually gives.
- `verdict`: "answers it", "answers part of it", or "does not answer it".
